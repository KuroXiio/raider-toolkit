Info, sources & legal

Where the data comes from, how fresh it is, and what is still missing.

Legal

Raider Toolkit is an unofficial fan project and is not affiliated with or endorsed by Embark Studios. ARC Raiders, its item names, item artwork and map art belong to Embark Studios AB. The home-page scene is original art drawn in code.

Data sources

Notes per tool

Workshop. Levels 1 to 3 of the six Workshop benches come from the game data (v1.42). Gunsmith IV, the Outpost and the Research Station come from October 2026 guides. Research node costs, and what is unlocked at each level, are only partly published. Stash counts are saved in this browser only.

Weapons. The data set lists the materials for each tier, not the Gunsmith level each upgrade needs, so that is only shown for crafting the weapon and the attachments. Amplification Module counts are not published, so they are shown as unknown, never guessed. Weapon and attachment costs, tier bonuses and repair costs are from the game data (v1.42); a dash in the tier table means the data set has no value for that tier. Blueprint locations are from community guides. Kinetic Converter, Horizontal Grip and Silencer III cannot be crafted: they are found as loot, and the game's quest and project data name a guaranteed source where there is one. Corrections from the 2.0 and 2.3 patch notes are applied: the Anvil is Rare and lost its tech-mod slot (the Anvil Splitter is now part of the Amplified Anvil), Tian Wen no longer sells the Anvil or Hullcracker, creds were removed so cred prices are gone, and six legendary blueprints can drop in any major map condition. The Bantam and Stiletto (new in 2.0) are listed as WIP until their recipes are published. Build codes contain only the weapon, tiers, amplification and attachments.

Maps. Map images are the in-game maps from the data set. Named areas, ziplines and per-map conditions come from community map pages; the full condition list is from the game data. Pendola Pass has no map image or area list in the sources used yet. The interactive-map buttons link to arcraidersmaps.app. Zoomed-in views load the full original images (Buried City 6144 px, Stella Montis 5120 px, Dam 4260 px, the rest about 4000 px). How sharp they look depends on the source: Dam and Spaceport have fine detail but film-grain, Blue Gate is softer, and Riven Tides is the softest; the data set has no sharper versions with area names on them.

Keys. What each key opens comes from the game's item descriptions, with door details, how to get it and what is inside from the community guides listed above. Guides sometimes disagree; where they do, both versions are shown. Map pins mark the named area printed on the game map, not the exact door, and only keys whose area is labelled on the map have a pin. Riven Tides and Pendola Pass keys have no pins: the Riven Tides map image has no area labels and there is no Pendola Pass map image yet.

Shopping list. Saved in this browser only. “Have” counts are shared across all groups and taken off the first groups first; the export lists what is still missing. Materials to craft an item come from the game data recipes.

Items. Stats, values, vendors, recycling and recipes are game data. Where-to-find notes come from the community guides listed above. Items added in update 2.x have no value or rarity in the data yet.
