RAIDER TOOLKIT COMPANION
WHAT THE APP DOES, AND WHAT IT DOESN'T

Last updated: 10 November 2026

The app is a few ordinary Windows windows that sit on top of other windows, the way Discord, a browser or a music player can:
- The in-game bar: a see-through window covering the screen, opened and closed with a keybind. It dims the game and shows a bar of widgets: the map with item and key search, your route (which you can plan, change and end there), your shopping list, followed quests and keys, and map conditions. It is an ordinary window on top of the game; closing it gives the keyboard and the clicks back to the game.
- Pinned widgets: widgets you pin in the bar stay on screen while you play, where you put them, with adjustable opacity. They are drawn by the same see-through window with the bar closed. In that state every click passes straight through it to the game, and it never takes the keyboard.
- The main window: the program itself, an ordinary window with a title bar and a taskbar button. It has a start page (open the bar, connect to raidkits.com, bring in a list or route) and settings.

IT NEVER:
- reads, scans or changes ARC Raiders' memory
- reads or changes the game's files, settings or logs
- captures, records or reads the screen
- injects code into the game or hooks into its graphics (it is not an in-game overlay like those that draw inside the game)
- sends keypresses, mouse movements or any other input to the game
- installs drivers or services, or runs as administrator
- opens, reads or watches the game's process, its folder or its window contents

WHAT IT DOES USE
- Data: the public Raider Toolkit data from raidkits.com, and what you type in yourself.
- Keybinds: the standard Windows hotkey registration (RegisterHotKey), the same feature Discord and Steam use for their shortcuts. It is not a keyboard hook and does not see any other keys. The map and route keybinds are only registered while the game or the app is in front, so other programs keep those keys. Every keybind can be changed or turned off in Settings > Keybinds.
- Which window is in front: to show pinned widgets only while you play, the app asks Windows twice a second for the title and class name of the window in front (GetForegroundWindow, GetWindowText, GetClassName). That is the same name the taskbar and Alt-Tab show. If it is "ARC Raiders", the overlay shows; otherwise it hides. If another program comes to the front while the in-game menu is open, the menu closes. Nothing about the game's process is opened or read, and nothing is saved or sent. Turn it off in Settings > Overlay > Only while you play, and the overlay shows all the time.
- Sync (optional, off until you turn it on): your shopping list, the route you sent from the site and the quests and keys you follow are kept the same as on raidkits.com through Raider Toolkit's sync service. See PRIVACY.txt.
- Updates: the Microsoft Store version is updated by the Store. The GitHub version asks GitHub for a newer version at start and every 6 hours (you can turn this off), and installs one only when you press Install. Some updates are marked as required: then the app asks you to install it before it starts (or quit), and starts as usual when you're offline. Updates are signed; the app refuses any update not signed with Raider Toolkit's key.
- Window permissions: the windows may only move, resize, show and hide themselves, let clicks pass through, see which screen they are on, open the in-game bar, and open raidkits.com and Discord links in your browser. The full list is in the source code, in companion/src-tauri/capabilities/default.json.

DISPLAY MODE
Use the game in Borderless or Windowed mode. In exclusive fullscreen Windows draws the game above everything else, so the bar and pinned widgets can't show; the app does nothing to get around that.

CHECK IT YOURSELF
The source code is public: https://github.com/KuroXiio/raider-toolkit (the companion folder). The installer is built from it by GitHub Actions.

THE GAME'S RULES STILL APPLY
Embark Studios decides which programs may be used with ARC Raiders. Their FAQ says overlays and game assistants are allowed only if they don't interfere with gameplay or give an unfair advantage, and asks players who are unsure to contact their support. The app is built to stay well inside that, but it is your choice and your account: see EULA.txt.

UNINSTALLING
Windows Settings > Apps > Installed apps > Raider Toolkit Companion > Uninstall. Tick "Delete the application data" to remove your saved list and settings too. The app adds no startup entries, services or drivers, so nothing is left running. Settings > Reset everything clears your data without uninstalling.
